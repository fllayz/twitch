# Twitch Account Promoter

Современное приложение для продвижения Twitch каналов с помощью ботов и ИИ-ассистента.

## Возможности

- Современный интерфейс с темной темой
- Управление множеством ботов через файл `bots.txt`
- Автоматический чат с настраиваемыми сообщениями и эмодзи
- Статистика в реальном времени (длительность стрима, зрители, сообщения)
- Встроенный чат с ИИ для помощи в продвижении
- Просмотр стрима в реальном времени
- Настраиваемая задержка между действиями ботов

## Подробное описание работы

### Подготовка к работе

1. **Настройка ботов**:
   - Создайте файл `bots.txt` в той же папке, где находится программа
   - Добавьте в него ботов в формате `login:token`
   - Каждый бот должен быть на новой строке
   - Пример:
     ```
     bot1:oauth:abcdef123456
     bot2:oauth:ghijk789012
     ```

2. **Настройка OpenAI**:
   - Создайте файл `.env` в той же папке
   - Добавьте в него ваш API ключ OpenAI:
     ```
     OPENAI_API_KEY=ваш_ключ_openai
     ```

### Запуск программы

1. **Запуск из исходного кода**:
   ```bash
   python twitch_promoter.py
   ```

2. **Запуск собранного .exe файла**:
   - Дважды кликните на `twitch_promoter.exe`
   - Или запустите через командную строку:
     ```bash
     twitch_promoter.exe
     ```

### Работа с интерфейсом

1. **Основные элементы управления**:
   - Поле "Введите канал для продвижения" - введите никнейм канала
   - Поле "Задержка (сек)" - установите интервал между действиями ботов
   - Кнопка "Загрузить ботов" - загружает ботов из файла `bots.txt`
   - Кнопка "Начать продвижение" - запускает/останавливает ботов
   - Кнопка "Включить авточат" - включает/выключает автоматический чат

2. **Панель статистики**:
   - Длительность стрима - показывает время работы
   - Зрителей - количество активных зрителей
   - Отправлено сообщений - общее количество сообщений
   - Активных ботов - количество работающих ботов

3. **Чат с ИИ**:
   - Введите вопрос в поле ввода
   - Нажмите Enter или кнопку "Отправить"
   - Дождитесь ответа (появится индикатор загрузки)
   - Ответ появится в окне чата

4. **Список ботов**:
   - Отображает всех загруженных ботов
   - Обновляется при нажатии кнопки "Загрузить ботов"

### Сборка в .exe файл

1. Установите PyInstaller:
   ```bash
   pip install pyinstaller
   ```

2. Соберите .exe файл:
   ```bash
   pyinstaller --onefile --windowed --icon=icon.ico twitch_promoter.py
   ```

3. Файлы для сборки:
   - `twitch_promoter.py` - основной файл программы
   - `requirements.txt` - зависимости
   - `bots.txt` - файл с ботами
   - `.env` - файл с API ключом
   - `icon.ico` - иконка программы (опционально)

4. После сборки:
   - .exe файл будет находиться в папке `dist`
   - Скопируйте его вместе с `bots.txt` и `.env` в нужную папку
   - Запустите .exe файл

## Установка

1. Убедитесь, что у вас установлен Python 3.8 или выше
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Создайте файл `.env` и добавьте ваш API ключ OpenAI:
   ```
   OPENAI_API_KEY=ваш_ключ_openai
   ```
4. Создайте файл `bots.txt` со списком ботов в формате:
   ```
   # Формат: login:token
   bot1:oauth:abcdef123456
   bot2:oauth:ghijk789012
   ```

## Получение токенов

### OpenAI API Key
1. Зарегистрируйтесь на [OpenAI](https://platform.openai.com/)
2. Создайте API ключ в разделе API Keys
3. Добавьте ключ в файл `.env`

### Twitch Token
1. Зарегистрируйтесь на [Twitch Developer Console](https://dev.twitch.tv/console)
2. Создайте новое приложение
3. Получите OAuth токен для каждого бота
4. Добавьте токены в файл `bots.txt`

## Требования

- Python 3.8+
- PyQt6
- requests
- python-dotenv
- twitchAPI
- openai
- pyinstaller (для сборки .exe)

## Безопасность

- Храните токены в файле `.env`
- Не публикуйте файл `bots.txt` с реальными токенами
- Используйте разные токены для разных ботов
- Регулярно обновляйте токены

## Поддержка

При возникновении проблем:
1. Проверьте правильность токенов
2. Убедитесь, что все зависимости установлены
3. Проверьте формат файла `bots.txt`
4. Проверьте наличие файла `.env` с API ключом OpenAI
5. При проблемах со сборкой .exe:
   - Убедитесь, что установлен PyInstaller
   - Проверьте наличие всех необходимых файлов
   - Попробуйте собрать без флага `--windowed`
